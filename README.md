# MP3 Плеер для Android

Плеер в стиле настольного [MP3 Плеера](https://github.com/SevereClaw/MP3-Player): тот же вид (скины
«Флешка», «Карманный», «Полночь», «Кассетный»), экранчик с бегущей строкой и текстом песни.

## Скачать

**[Releases → последняя сборка → MP3Player.apk](../../releases/latest)** — открой на телефоне и установи.
Новая сборка появляется сама после каждого изменения (вкладка **Actions**); обновление ставится поверх.

## Что умеет

- Сам находит всю музыку на телефоне — mp3, flac, wav, m4a, ogg, opus… (с тегами, обложками, альбомами).
- Вкладки: **Плеер** (скин с ПК + перемотка и кнопки), **Треки**, **Альбомы**, **Артисты**, **Папки** — везде поиск.
- Мини-плеер внизу на всех вкладках.
- Звуки кнопок и включения — как у плеера на ПК (громкость — в ⚙).
- Играет в фоне: уведомление, экран блокировки, кнопки наушников/Bluetooth, пауза при отключении наушников.
- Помнит, что играло, и продолжает с того же места.
- Текст песни (.lrc): в ⚙ один раз укажи папку, где лежат .lrc (можно всю «Музыку»).
- Скины «Флешка», «Карманный», «Полночь», «Кассетный» и цвет подсветки.

Плеер нажимается как настоящий: боковые кнопки ⏮ ⏯ ⏭ 🔀, экранчик — пауза.
