# MP3 Плеер для Android

Плеер в стиле настольного [MP3 Плеера](https://github.com/SevereClaw/MP3-Player): тот же вид (скины
«Флешка», «Карманный», «Полночь», «Кассетный»), экранчик с бегущей строкой и текстом песни.

## Скачать

**[Releases → последняя сборка → MP3Player.apk](../../releases/latest)** — открой на телефоне и установи.
Новая сборка появляется сама после каждого изменения (вкладка **Actions**); обновление ставится поверх.

## Что умеет

- Папки с музыкой («Мои папки»): переключение, запоминает трек и место в каждой папке.
- Играет в фоне: уведомление, экран блокировки, кнопки наушников/Bluetooth, пауза при отключении наушников.
- Текст песни из `.lrc` рядом с треком.
- Перемешивание, повтор, поиск по списку, скины и цвет подсветки.

Касания по плееру — как по настоящему: боковые кнопки ⏮ ⏯ ⏭ 🔀, экран — пауза,
низ плеера — следующая папка, долгое нажатие — список папок.
